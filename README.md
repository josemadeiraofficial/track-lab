# Track Lab

Lokální webová aplikace pro analýzu tracků před vydáním na label.

## Co umí
- Nahrání tracku (WAV, MP3, AIFF)
- Poznámky (žánr, tempo, co je špatně)
- AI analýza s kartami hodnot (LUFS, true peak, stereo, dynamika)
- Detailní rozbor + konkrétní opravy pro Ableton Live 12
- Offline režim (základní info bez API)
- Kopírování rozboru do schránky

## Jak spustit
1. Stáhni `index.html`
2. Otevři v prohlížeči (dvojklik)
3. Pro plnou AI analýzu vlož API klíč od OpenAI nebo Anthropic
4. Nahraj track, napiš poznámky, klikni na ANALYZOVAT

## API klíče
- OpenAI: https://platform.openai.com/api-keys
- Anthropic: https://console.anthropic.com/

Klíč se neukládá — zůstává jen v prohlížeči.

## Offline režim
Bez API klíče funguje základní info o souboru. Plná analýza vyžaduje klíč.
